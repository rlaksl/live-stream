## 완료 조건

- [x] 플레이어 아래: 제목(24px) / 카테고리 칩 · 시청 N명 · 시작 HH:mm / 오른쪽에 팔로우(테두리)·후원하기(주황) 버튼.
- [x] 방송자 카드(이니셜 원 + 닉네임). 소유자용 송출 화면·수정·삭제 버튼은 유지.
- [x] 오른쪽: 후원(합계 주황 강조 + 내역) 위, 댓글 아래. 후원하기 버튼은 제목 줄로 옮긴다.
- [x] 댓글: 방송자 닉네임은 형광펜, 내 닉네임은 주황 글씨, 내 댓글에만 수정·삭제.
- [x] 메시지가 있는 확정 후원을 댓글 목록에 시간순으로 섞어 표시(DB 변경 없음). 댓글과 구분되게 주황 형광펜 닉네임 + "5,000원 후원" 표시, 수정·삭제 버튼 없음. 섞는 함수는 Vitest.
- [x] 후원 패널은 합계 그대로 유지, 내역은 닉네임·금액만.
- [x] 플레이어 위 소리·전체 화면 버튼(지금 플레이어 동작과 겹치면 기존 것 유지).
- [x] 대기: 졸린 눈 + "곧 시작합니다" + 예정 시각. 종료: X 눈 + NO SIGNAL + "방송이 종료되었습니다" + 녹화 있으면 `다시보기 재생`.
- [x] 모바일: 플레이어 → 정보 → 후원 → 댓글 한 열.

## Comments

- 2026-11-19: 사용자 결정 — 후원 메시지는 댓글창에 구분 표시(형광펜 닉네임 + 금액 후원, 수정·삭제 없음), 후원 패널 합계 유지.
- 2026-11-19: 구현. 제목 줄(상태·카테고리 칩·시작 시각 + 팔로우/후원하기), 방송자 카드(이니셜 + 닉네임 + 팔로워 N명 공개), 오른쪽 `WatchAside`(후원 폴링을 한 곳에서 하고 후원 패널·댓글창에 나눠 줌). 후원 패널은 합계 + 닉네임·금액. 댓글: 방송자 형광펜, 내 닉네임 주황, 후원 메시지는 왼쪽 주황 선 + 형광펜 닉네임 + "N원 후원"(수정·삭제 없음, `comments/feed.ts` + 테스트). 플레이어: LIVE 배지(주황·Silkscreen), 시청 N명, 소리 켜기(자동 재생 막힐 때만), 전체 화면 버튼. 대기(졸린 눈·대기 중)·종료(X 눈·NO SIGNAL·녹화 있으면 다시보기 재생) 화면.
- 시청자 수는 실시간 갱신되는 플레이어 오른쪽 위에만 둔다(제목 줄에 서버 값으로 또 쓰면 서로 달라질 수 있음). 팔로우 버튼에서 수를 빼고 방송자 카드로 옮겼다.
- 크롬 확인: B로 종료 방송(1440·390, 넘침 0) — 팔로잉 상태, 후원하기, 내 댓글 수정·삭제. 메시지 있는 후원이 댓글창에 섞이는 화면은 실제 결제가 필요해 단위 테스트로만 확인 → 실기기 확인 항목.
