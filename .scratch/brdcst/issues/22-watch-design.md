# 시청 화면 시안 반영

Status: ready-for-agent
Blocked by: 20
출처: `docs/design/brdcst-design/Watch.dc.html`, `States.dc.html`

## 완료 조건

- [ ] 플레이어 아래: 제목(24px) / 카테고리 칩 · 시청 N명 · 시작 HH:mm / 오른쪽에 팔로우(테두리)·후원하기(주황) 버튼.
- [ ] 방송자 카드(이니셜 원 + 닉네임). 소유자용 송출 화면·수정·삭제 버튼은 유지.
- [ ] 오른쪽: 후원(합계 주황 강조 + 내역) 위, 댓글 아래. 후원하기 버튼은 제목 줄로 옮긴다.
- [ ] 댓글: 방송자 닉네임은 형광펜, 내 닉네임은 주황 글씨, 내 댓글에만 수정·삭제.
- [ ] 메시지가 있는 확정 후원을 댓글 목록에 시간순으로 섞어 표시(DB 변경 없음). 댓글과 구분되게 주황 형광펜 닉네임 + "5,000원 후원" 표시, 수정·삭제 버튼 없음. 섞는 함수는 Vitest.
- [ ] 후원 패널은 합계 그대로 유지, 내역은 닉네임·금액만.
- [ ] 플레이어 위 소리·전체 화면 버튼(지금 플레이어 동작과 겹치면 기존 것 유지).
- [ ] 대기: 졸린 눈 + "곧 시작합니다" + 예정 시각. 종료: X 눈 + NO SIGNAL + "방송이 종료되었습니다" + 녹화 있으면 `다시보기 재생`.
- [ ] 모바일: 플레이어 → 정보 → 후원 → 댓글 한 열.

## Comments

- 2026-11-19: 사용자 결정 — 후원 메시지는 댓글창에 구분 표시(형광펜 닉네임 + 금액 후원, 수정·삭제 없음), 후원 패널 합계 유지.
