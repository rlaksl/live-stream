# 후원 (토스페이먼츠 테스트 결제)

Status: resolved
Blocked by: 03

방송 상세에서 그 방송의 방송자에게 후원. 결제창(SDK v2, API 개별 연동 키). 처음엔 결제위젯이었으나 2026-11-18 사용자 결정으로 변경. 흐름은 spec의 후원 절과 ADR-0003.

## 완료 조건

- [x] 금액 1,000/5,000/10,000원 또는 직접 입력(1,000원 이상), 메시지 선택(≤100자)
- [x] 비로그인 거절, 자기 방송 거절, 모든 상태 방송 허용
- [x] 서버가 `pending` 생성 → 승인 시 저장 금액과 비교 → confirm API → `confirmed`
- [x] 웹훅은 토스에 다시 조회해 같은 확정 함수 사용, 조건부 업데이트로 1회만 확정
- [x] 방송별 확정 후원 내역(닉네임·금액·메시지)과 합계 표시
- [x] Vitest: 금액 불일치 거절, 중복 통지 1회 적립, 자기 방송 거절

## Comments

- 2026-11-18: 로직은 features/donations/(policy·confirm + test). 확정 함수 `confirmDonation`을 성공 페이지(/donations/success)와 웹훅(/api/toss/webhook)이 같이 쓴다. 후원 화면은 /broadcasts/[id]/donate, 내역은 GET /api/broadcasts/[id]/donations를 5초 폴링.
- 로컬 E2E(headless Chrome): B가 A 방송에 10,000원 퀵계좌이체(테스트: 번호 자동 입력, 비밀번호 000000) → 성공 페이지 확정 → 내역·합계 표시. 새로고침·웹훅 3회 반복에도 1건, 금액 조작 URL은 거절, 가짜 paymentKey 웹훅은 무시. 확정을 pending으로 되돌린 뒤 웹훅만으로 확정되는 것도 확인.
- 카드·토스페이는 테스트 환경에서도 실제 카드사/토스 앱 인증 화면이 떠서 자동화하지 못함. 시연·심사 안내는 퀵계좌이체로.
- 결제창을 닫거나 실패하면 `pending` 행이 남는다(합계 미포함, 설계대로).
- (초기) 토스 문서 공개 테스트 키(test_gck_docs/test_gsk_docs)로 결제위젯 검증. 이후 본인 상점 키로 교체.
- 배포 E2E(https://brdcst-gray.vercel.app): B → A 방송 5,000원 퀵계좌이체 → 후원 완료, 토스 조회 DONE. 금액 조작 URL 거절, 웹훅 2회 재전송에도 합계 15,000원(로컬 10,000 + 배포 5,000) 그대로, 가짜 웹훅 무시.
- 테스트 방송 "후원 테스트 방송"(0bb0955c…)과 확정 2건·pending 여러 건이 DB에 남아 있다.

### 2026-11-18 본인 상점 키(API 개별 연동, test_ck/test_sk)로 전환

- 결제위젯 SDK가 API 개별 연동 키를 거부해서 결제창(`payment().requestPayment({ method: "CARD" })`, 카드·간편결제 통합결제창)으로 변경. 확정 흐름(ADR-0003)은 그대로.
- 토스 API 키 접근 정책이 "국가: 대한민국"만 허용 → Vercel 함수가 미국(iad1)에서 돌아 승인·조회가 거절됨("API 키 접근 정책에 의해 허용되지 않은 요청"). `vercel.json`에 `regions: ["icn1"]` 추가 후 해결(`x-vercel-id: icn1::icn1`).
- 웹훅 조회 실패를 200으로 돌려 토스가 재전송하지 않던 문제 수정: 조회 실패는 502(토스 재전송), 없는 주문·금액 불일치만 200.
- **실제 토스 웹훅 확인(사용자 직접 결제):** 배포 주소 결제창에서 카카오페이 1,000원(orderId 6d065ec4…). 토스 API 로그 `/v1/payments/confirm` 200, 웹훅 전송 내역 `PAYMENT_STATUS_CHANGED` 성공(23:27:23). 토스에 웹훅이 2개 등록돼 같은 통지가 두 번 왔을 수 있으나 DB는 `confirmed` 1건, 해당 방송 합계 1,000원(한 번만 적립).
- key-in API 승인(테스트용 우회)에는 토스가 웹훅을 보내지 않았다. 그 주문(bf572725…, 토스 DONE)은 배포 웹훅 핸들러에 3번 동시 요청 → 토스 재조회로 확정, 합계 16,000 → 17,000원(1회만 적립).
- 남은 `pending`은 토스 주문 조회 결과 READY(결제창만 열고 닫음) 5건, NOT_FOUND(결제 시도 없음) 6건 → 결제되지 않았으므로 그대로 둔다. 테스트 데이터는 시연용으로 유지.
- 카드사 인증(신한 SOL, KB Pay 등)은 테스트 모드에서도 실제 앱 인증이라 브라우저 자동화 불가. 시연·심사 안내는 카카오페이 등 간편결제로.
