# 후원 (토스페이먼츠 테스트 결제)

Status: ready-for-agent
Blocked by: 03

방송 상세에서 그 방송의 방송자에게 후원. 결제위젯 v2. 흐름은 spec의 후원 절과 ADR-0003.

## 완료 조건

- [ ] 금액 1,000/5,000/10,000원 또는 직접 입력(1,000원 이상), 메시지 선택(≤100자)
- [ ] 비로그인 거절, 자기 방송 거절, 모든 상태 방송 허용
- [ ] 서버가 `pending` 생성 → 승인 시 저장 금액과 비교 → confirm API → `confirmed`
- [ ] 웹훅은 토스에 다시 조회해 같은 확정 함수 사용, 조건부 업데이트로 1회만 확정
- [ ] 방송별 확정 후원 내역(닉네임·금액·메시지)과 합계 표시
- [ ] Vitest: 금액 불일치 거절, 중복 통지 1회 적립, 자기 방송 거절
