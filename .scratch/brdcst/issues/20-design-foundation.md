# 시안 기초: 색·라운드·로고·헤더·마스코트

Status: done
출처: `docs/design/brdcst-design/DESIGN.md`

## 완료 조건

- [x] 색 토큰을 시안 값으로: 배경 #0B0B0C, 카드 #121214, 테두리 #26262A, 본문 #F2F1EE, 보조 #A3A3AB, 포인트 #FF8A1F 하나. 빨간 `--live`는 없애고 LIVE 배지는 주황 + Silkscreen.
- [x] 라운드 사이트 전체 4px(칩·토글 같은 알약 모양만 둥글게). 홈·시청 시안의 12~16px은 따르지 않는다. 강조 박스는 배경 없이 주황 테두리.
- [x] 형광펜 스타일(주황 배경 + 검정 글씨) 한 곳에 정의해 댓글·알림·탭 오디오 안내에서 같이 쓴다.
- [x] 한글 `word-break: keep-all` 전역.
- [x] 로고에서 마스코트 그림 제거(픽셀 글꼴 BRDCST + broadcast만).
- [x] 헤더 메뉴: 홈 / 다시보기 / 팔로잉(`/following`, 티켓 25) / 편성표 + 로그인 / 방송하기. 390px에서 겹치지 않게 줄바꿈.
- [x] 마스코트는 색과 표정만 바꾼다. 색: 아이보리 몸체, 은색 가는 안테나, 주황 픽셀 얼굴, 검정 외곽선 없음.
- [x] 애니메이션은 지금 그대로 유지: 랜딩·로딩의 통통 튀다 멈추는 동작, 화면 속 노이즈 지직거림과 색 글리치. 시안의 마스코트는 정지 그림이라 움직임 기준으로 쓰지 않는다.
- [x] 마스코트 얼굴 `surprised`(놀란 눈 ㅇ0ㅇ) 추가 → "방송 없음" 빈 상태. 정지 SVG(`/mascot/[face]`)도 같은 색·얼굴로.
- [x] 크롬 1440 / 768 / 390 스크린샷 확인.

## Comments

- 2026-11-19: 사용자 결정 — 라운드 전체 4px. 팔로잉은 별도 페이지(티켓 25). 마스코트는 색·표정만 바꾸고 애니메이션은 그대로.
- 2026-11-19: 구현. 색 토큰(`.dark`)을 시안 hex로, 라운드 토큰 전부 4px, `--live`(빨강) 제거 → LIVE 배지 주황 + Silkscreen. `highlight` 유틸리티 추가. 본문 `keep-all` + `overflow-wrap: anywhere`(제목의 `break-all` 제거). 헤더: 로고 글자만, 주 메뉴(홈·편성표, 현재 메뉴 강조), 로그인/로그아웃 + 방송하기(비로그인은 로그인 후 복귀). 회원가입 버튼은 헤더에서 빠지고 로그인 화면 링크로. `다시보기`·`팔로잉` 메뉴는 페이지가 생기는 티켓 21·25에서 추가(없는 페이지로 가는 링크를 배포하지 않으려고).
- 마스코트: 아이보리 몸체·은색 안테나(끝 공 제거)·몸체 외곽선 제거, `surprised` 얼굴 추가(정지 SVG 포함). 튀기·노이즈·글리치는 그대로.
- 크롬(puppeteer) 390·768·1440: 가로 넘침 0, 390에서 메뉴가 아랫줄로 내려감.
