# 회원가입·로그인·로그아웃과 테스트 계정

Status: ready-for-agent
Blocked by: 01

이메일+비밀번호+닉네임 가입(이메일 인증 없음), 로그인, 로그아웃, 쿠키 세션 기반 인증 상태 관리. 로그인·가입은 서버 액션으로 처리한다.

## 완료 조건

- [ ] 가입 시 닉네임 2~12자·중복 검사
- [ ] 헤더에 로그인 상태(닉네임/로그아웃) 표시
- [ ] 로그인 화면의 "테스트 계정 A/B로 로그인" 버튼이 동작한다
- [ ] 서버에서 현재 사용자를 얻는 함수 하나(`getCurrentUser`)로 모든 기능이 인증을 확인한다
