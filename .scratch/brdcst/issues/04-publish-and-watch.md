# 송출과 시청 (PC 화면 공유, 모바일 카메라)

Status: ready-for-human
Blocked by: 03

LiveKit으로 방송 시작·송출·시청·종료. 방송하기 화면 하나에서 PC는 화면 공유(+탭/시스템 소리)+마이크, 모바일은 카메라+마이크.

## 완료 조건

- [x] 방송 시작: 소유자만, `대기`→`방송 중`, 사용자당 `방송 중` 1개
- [x] 송출 토큰: 소유자 + `방송 중`일 때만 `canPublish`; 시청 토큰은 구독 전용, 비로그인 가능
- [x] PC: 화면 영상 + 탭 소리 + 마이크가 다른 기기에서 재생된다 (Chrome/Edge 안내 문구)
- [x] 모바일: 카메라 영상이 다른 기기에서 재생된다, 전면/후면 전환
- [ ] 모바일: 마이크 음성이 다른 기기에서 들린다
- [x] 방송 종료: 소유자만, `방송 중`→`종료`, LiveKit 방 삭제로 송출 중단, 시청 화면이 종료 상태로 바뀐다
- [x] 방송 중 시청자 수 표시
- [x] Vitest: 토큰 발급 규칙(소유자/다른 사용자/비로그인 × 대기/방송 중/종료), 시작·종료 권한

## Comments

- 2026-11-18: 로컬 E2E(가짜 미디어 Chromium)로 PC 화면 공유·모바일 카메라 송출 → 비로그인 시청 수신 → 종료까지 통과. 남은 것: 실제 탭 소리(Chrome)와 실제 휴대폰 확인 — 배포 후 사용자 확인.
- 2026-11-18 사용자 실기기 확인(배포 주소): PC Chrome 화면 공유 + 탭 소리 + 마이크 → 휴대폰 시청, 두 소리 모두 들림. 휴대폰 카메라 송출(전면/후면 전환) → PC 시청. 방송 종료 시 시청 화면이 종료 상태로 바뀜. 모바일 마이크 음성은 확인 언급이 없어 남김.
