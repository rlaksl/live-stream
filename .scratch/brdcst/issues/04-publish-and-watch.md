# 송출과 시청 (PC 화면 공유, 모바일 카메라)

Status: ready-for-agent
Blocked by: 03

LiveKit으로 방송 시작·송출·시청·종료. 방송하기 화면 하나에서 PC는 화면 공유(+탭/시스템 소리)+마이크, 모바일은 카메라+마이크.

## 완료 조건

- [ ] 방송 시작: 소유자만, `대기`→`방송 중`, 사용자당 `방송 중` 1개
- [ ] 송출 토큰: 소유자 + `방송 중`일 때만 `canPublish`; 시청 토큰은 구독 전용, 비로그인 가능
- [ ] PC: 화면 영상 + 탭 소리 + 마이크가 다른 기기에서 재생된다 (Chrome/Edge 안내 문구)
- [ ] 모바일: 카메라 영상 + 마이크가 다른 기기에서 재생된다, 전면/후면 전환
- [ ] 방송 종료: 소유자만, `방송 중`→`종료`, LiveKit 방 삭제로 송출 중단, 시청 화면이 종료 상태로 바뀐다
- [ ] 방송 중 시청자 수 표시
- [ ] Vitest: 토큰 발급 규칙(소유자/다른 사용자/비로그인 × 대기/방송 중/종료), 시작·종료 권한
