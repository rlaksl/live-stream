## 완료 조건

- [ ] 새 확정 후원이 오면 시청 화면과 방송하기 화면에 5초 배너. PC는 플레이어 위 가운데, 모바일은 플레이어 아래쪽 한 줄.
- [ ] 내용: [닉네임 형광펜] 님이 [금액] 원 후원. 닉네임·금액만 크고 굵게, 가운데 정렬. 메시지는 배너에 넣지 않는다.
- [ ] 배경은 옅은 흰 막 + 뒤 흐림, 주황 테두리(검정 배경 금지). 작은 X 눈 마스코트(PC).
- [ ] 소리: 효과음(코드 생성, Web Audio) → `speechSynthesis`로 "닉네임님 금액 원 후원". "후원 음성 켜짐/꺼짐" 버튼(기본 켜짐, 브라우저 저장).
- [ ] 페이지를 연 시점 이전의 후원은 알리지 않는다. 여러 건이 오면 차례로.
- [ ] 화면을 한 번 누르기 전에는 소리가 막힐 수 있음, 한국어 음성이 없으면 효과음·배너만 — 화면 안내 또는 README에 적는다.
- [ ] 감지 로직(이전 목록과 비교해 새 항목 고르기)은 Vitest.
- [ ] 크롬에서 B 후원 → A 방송하기·C 시청 화면에 배너·음성 확인.
