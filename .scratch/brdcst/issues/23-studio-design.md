## 완료 조건

- [x] 왼쪽: 소스 카드 2개(화면 공유 / 카메라, 선택은 주황 2px 테두리), 미리보기("미리보기 · 아직 송출 전" 배지), 장치 상태 3칸(화면·마이크·공유 소리 — 정상은 흰 체크박스, 문제는 주황 빈 네모 + 주황 테두리), 공유 소리가 없으면 형광펜 안내 "공유 창에서 '탭 오디오 공유'를 켜 주세요".
- [x] 두 단계 유지: 등록(`/broadcasts/new`) → 바로 송출 화면(`/broadcasts/[id]/studio`). 등록만으로는 `대기`이고, "방송 시작"을 눌러야 LIVE.
- [x] 등록 화면을 시안의 "방송 정보" 패널과 같은 스타일로(입력칸·카테고리·예정 시간, 라운드 4px, 주황 테두리 강조). 수정 화면도 같은 폼이라 함께 바뀐다.
- [x] 송출 화면 오른쪽 "방송 정보" 패널: 제목·카테고리·예정 시간을 같은 스타일로 읽기 전용 표시 + `수정` 링크, 녹화 토글("최대 10분 · 끝나면 다시보기에 올라가요"), 방송 시작, "연결과 송출이 확인된 뒤에 LIVE로 바뀝니다." — 등록 화면과 자연스럽게 이어 보이게.
- [x] 수정·삭제는 방송 상세에서도 소유자가 할 수 있게 유지.
- [x] 티켓 12의 시작 실패 복구·중복 시작 차단 동작은 그대로 유지(회귀 확인).
- [x] 모바일은 한 열, 카메라 전환·마이크 끄기·방송 종료 버튼 유지.

## Comments

- 2026-11-19: 사용자 결정 — 두 단계 유지, 등록 화면을 방송 정보 패널 스타일로 맞추고 등록 후 바로 송출 화면. 등록만으로 LIVE가 되면 안 된다. 상세의 수정·삭제 유지.
- 2026-11-19: 구현. 등록·수정 폼을 "방송 정보" 패널 모양으로(`fieldClass` 공통, 4px, 포커스 시 주황 테두리). 등록 화면 안내 "1. 방송 정보 → 2. 송출 화면 … '방송 시작'을 눌러야 LIVE". 송출 화면: 왼쪽 소스 카드·미리보기(배지)·장치 상태 3칸(흰 체크/주황 빈 네모)·공유 소리 없으면 형광펜 안내 + "다시 고르기"(미리보기를 버리고 소스 선택으로), 오른쪽 방송 정보(읽기 전용 + 수정 링크, 방송 중엔 링크 숨김)·녹화 토글·큰 버튼(미리보기 시작/방송 시작/방송 종료). 시작·종료 로직(티켓 12 복구·중복 차단)은 손대지 않았다.
- 공유 소리 상태는 트랙이 있는지로 판단(실제 소리 크기 감지는 하지 않음).
- 크롬(가짜 카메라·마이크) 확인: A로 등록 → 송출 화면 이동, 상세는 `대기` 그대로 → 미리보기 → 방송 시작 → 상세 LIVE → 방송 종료 → 상세 종료. 녹화는 켜지 않음. 390 등록·수정 넘침 0. 테스트 방송 "디자인 반영 송출 확인"(64006144…, 종료)이 DB에 남아 있다(삭제 금지 규칙).
- 실기기: PC 화면 공유 + 탭 소리에서 장치 상태 3칸과 형광펜 안내가 맞게 바뀌는지 확인 필요.
