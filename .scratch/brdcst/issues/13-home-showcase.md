### 시안 반영 (2026-11-19 추가)

- [x] 대표 영상을 캐러셀로: 방송 중 먼저, 그 뒤 다시보기. 좌우 화살표 + 점(현재 점은 길게, 주황). 배지 LIVE(주황)/REPLAY(흰색), 오른쪽 위 시청자 수 또는 재생 시간, 왼쪽 아래 `LIVE · 시청하기`/`다시보기 재생`. 아래에 제목과 `닉네임 · 카테고리`.
- [x] 오른쪽 소개 패널: "지금 켜면, 바로 방송." + 설명 + `내 방송 시작`(주황) / `다시보기 재생`(테두리) + "로그인하지 않아도 시청할 수 있어요." 시안 패널에는 마스코트가 없지만, 랜딩의 통통 튀는 마스코트는 유지해야 하므로 위치는 결정 필요(추천: 패널 제목 위 작게).
- [x] 카테고리 칩(전체 + 6개, 알약 모양). 누르면 `/broadcasts?category=`로 이동.
- [x] 방송 중 카드 그리드(최소 280px), "전체 보기". 비었으면 놀란 눈 마스코트 빈 상태(티켓 20 얼굴) + `내 방송 시작`.
- [x] 최근 다시보기 2장(최소 420px), 오른쪽 아래 재생 시간(녹화 시작~종료로 계산), "다시보기 전체" → `/recordings`(티켓 21).

## Comments

- 2026-11-19: 홈 = 대표 영상 + 내 방송 시작 → 방송 중 → 최근 다시보기(6개). 전체 방송은 `/broadcasts`로 분리. PC·모바일(390px) 스크린샷 확인, 가로 넘침 없음.
- 썸네일: 녹화 앞부분 1초 지점 프레임을 `<video preload="metadata">`로 보여준다. HLS를 직접 재생 못 하는 브라우저는 hls.js(버퍼 2초)로 같은 프레임을 불러온다. 프레임이 그려지기 전(iOS 등)은 마스코트.
- 사전 확인: Chrome 158 headless에서 `canPlayType("application/vnd.apple.mpegurl")` = "maybe", 공개 HLS 테스트 스트림에 `#t=10`을 붙이자 실제 프레임이 그려짐.
- 남은 것: 실제 BRDCST 녹화(티켓 14)로 홈 썸네일이 크롬에서 보이는지 확인.
- 2026-11-19 (시안 반영): 캐러셀 `features/home/featured-carousel.tsx`(방송 중 최대 5 + 다시보기 최대 5). 방송 중 슬라이드는 방문자마다 LiveKit 연결을 만들지 않도록 마스코트. 소개 패널에 작은 튀는 마스코트(랜딩 동작 유지). 카테고리 칩은 `features/broadcasts/category-chips.tsx`로 공통화(홈·전체 방송·다시보기). 방송 중이 없으면 놀란 눈 빈 상태. 카드(방송·녹화)를 시안 모양으로 변경(썸네일 박스 + 아래 제목·메타).
- 크롬 확인: 임시 슬라이드를 로컬에서만 넣어 다음/이전 순환·점 이동 확인(커밋 안 함). 1440·390 가로 넘침 0. 실제 데이터(라이브·녹화)가 로컬 DB에 없어 실데이터 캐러셀은 시연 녹화(14) 뒤 확인 필요.
- 팔로우한 방송자 섹션은 `/following`(25)이 생길 때 홈에서 뺀다.
