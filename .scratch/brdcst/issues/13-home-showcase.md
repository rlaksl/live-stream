## 완료 조건

- [x] 홈 상단 대표 영상: 방송 중이 있으면 `LIVE · 시청하기`, 없으면 최근 녹화 `다시보기 재생`.

- [ ] 크롬에서 썸네일이 실제로 보이는지 확인(녹화가 HLS라 `<video preload="metadata">`만으로는 불확실). 안 되면 다른 방법 제안.

## Comments

- 2026-11-19: 홈 = 대표 영상 + 내 방송 시작 → 방송 중 → 최근 다시보기(6개). 전체 방송은 `/broadcasts`로 분리. PC·모바일(390px) 스크린샷 확인, 가로 넘침 없음.
- 썸네일: 녹화 앞부분 1초 지점 프레임을 `<video preload="metadata">`로 보여준다. HLS를 직접 재생 못 하는 브라우저는 hls.js(버퍼 2초)로 같은 프레임을 불러온다. 프레임이 그려지기 전(iOS 등)은 마스코트.
- 사전 확인: Chrome 158 headless에서 `canPlayType("application/vnd.apple.mpegurl")` = "maybe", 공개 HLS 테스트 스트림에 `#t=10`을 붙이자 실제 프레임이 그려짐.
- 남은 것: 실제 BRDCST 녹화(티켓 14)로 홈 썸네일이 크롬에서 보이는지 확인.
