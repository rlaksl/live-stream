## 3. 사용자가 실기기로 확인할 것

1. PC 크롬 실제 화면 공유: 화면 + 탭 오디오 공유 + 마이크 → 송출 화면 장치 상태 3칸 모두 체크, 탭 오디오를 끄면 형광펜 안내.
2. 실제 후원 알림: 방송 중에 시청자B로 1,000원(카카오페이) → 시청·송출 화면에 배너, 효과음 → 한국어 음성(화면을 한 번 누른 뒤), 메시지가 댓글창에 표시.

## 4. 참고

- 시연 계정(`demo@example.com`) 비밀번호는 사용자 요청으로 재설정했다. 저장소·파일에는 넣지 않았다.
- 녹화 한도 사용(오늘): 휴대폰 테스트 약 1분, PC 가짜 카메라 테스트 약 26초, 시연 녹화 약 90초.
- 휴대폰 카메라 시연 다시보기는 사용자 요청으로 삭제했다. 시연 다시보기는 PC 화면 공유 1개.
- PC 시연 영상 오른쪽 위의 "LIVE 00:00" 시계는 슬라이드에 그린 것이다. 사용자 결정으로 그대로 둔다.
