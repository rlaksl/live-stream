## 사용자가 실기기로 확인할 항목

1. PC 크롬: 화면 공유 + 탭 오디오 공유 + 마이크 → 송출 화면 장치 상태 3칸이 모두 흰 체크, 탭 오디오를 끄면 "공유 소리 감지 안 됨" + 형광펜 안내.
2. 휴대폰: 카메라 소스, 카메라 전환, 송출 화면 한 열 배치.
3. 실제 후원(퀵계좌이체): 시청 화면과 방송하기 화면에 배너, 효과음 → 한국어 음성(화면을 한 번 누른 뒤), 메시지가 댓글창에 표시.
4. 시연 녹화 2개(티켓 14) 뒤 홈 캐러셀·다시보기 카드에 실제 프레임 썸네일이 보이는지.
