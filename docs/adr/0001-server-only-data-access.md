# 브라우저는 DB에 직접 접근하지 않고 모든 권한 검증은 앱 서버에서 한다

Supabase는 보통 브라우저가 DB에 직접 접근하고 RLS 정책으로 권한을 거는 방식으로 쓰지만, 이 프로젝트는 모든 읽기·쓰기를 Next.js 서버(Route Handler/Server Action)를 거쳐서 하고, 로그인 상태·방송 소유자·댓글 작성자 권한을 서버 코드 한곳에서 확인한다. 권한 로직을 테스트로 증명하기 쉽고, 공모전 평가 항목인 "서버에서 권한 확인"의 근거 코드 위치를 명확히 보여줄 수 있기 때문이다. Supabase 테이블은 RLS를 켜되 정책을 두지 않아 외부 직접 접근을 막는다.

## Consequences

- Supabase Realtime을 쓸 수 없으므로 댓글 목록은 몇 초 간격 폴링으로 갱신한다.
