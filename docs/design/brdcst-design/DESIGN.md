# BRDCST 화면 시안 (구현 기준)

원본 캔버스: https://claude.ai/artifact/UZwbjsAcpvnwHqHhqKE6Dn
이 폴더의 *.dc.html 은 시안 원본이다. 화면 구조·색·크기를 참고하고, 코드 형식(dc 문법)은 따르지 않는다.

## 화면
- Main: 홈. 대표 영상 캐러셀(라이브 먼저, 없으면 다시보기 / 좌우 화살표 + 점) → 소개 패널("지금 켜면, 바로 방송.", 내 방송 시작 / 다시보기 재생) → 카테고리 칩 → 방송 중 카드 → 최근 다시보기 2장
- Watch: 방송 상세. 플레이어 + 제목·카테고리·시청자 수 + 팔로우·후원 버튼 / 오른쪽 후원 합계·내역, 댓글
- Studio: 방송하기. 소스 선택(화면 공유/카메라), 미리보기, 장치 상태 3칸, 탭 오디오 안내, 방송 정보(제목·카테고리·예정 시간), 녹화 토글, 방송 시작
- Replays: 다시보기 목록. 카테고리 칩 + 카드 그리드
- States: 빈·종료 상태 마스코트(대기 졸린 눈 / 종료 X눈 / 방송 없음 놀란 눈 ㅇ0ㅇ)
- DonationAlert: 후원 알림 배너

## 디자인 규칙
- 배경 #0B0B0C, 카드 #121214, 테두리 #26262A, 본문 #F2F1EE, 보조 글씨 #A3A3AB
- 포인트 #FF8A1F 하나. 초록 등 다른 강조색 쓰지 않음. 글리치에만 마젠타·시안
- 라운드 4px (칩·토글 같은 알약 모양만 둥글게)
- 강조 박스는 배경색 없이 주황 테두리만
- 형광펜: 주황 #FF8A1F 배경 + 검정 글씨(그림자 없음). 방송자 닉네임(댓글), 후원자 닉네임(알림), 탭 오디오 안내 문구에 사용
- 장치 상태: 정상 = 흰 체크박스, 문제 = 주황 빈 네모
- 로고: 픽셀 글꼴 "BRDCST" + 작은 "broadcast". 로고에 마스코트 넣지 않음
- 글꼴: Noto Sans KR(본문), Silkscreen(로고·LIVE 배지)
- 한글은 단어 단위 줄바꿈(word-break: keep-all)
- 마스코트: 아이보리 몸체, 은색 가는 안테나, 주황 픽셀 얼굴

## 후원 알림
- 플레이어 위(모바일은 플레이어 아래쪽)에 5초 표시
- 내용: [닉네임 형광펜] 님이 [금액] 원 후원 — 닉네임·금액 숫자만 크게 굵게, 나머지 작게. 가운데 정렬
- 후원 메시지는 알림에 넣지 않고 댓글창에 표시
- 배경: 옅은 흰 막 + 뒤 흐림(유리 느낌), 주황 테두리. 검정 배경 쓰지 않음
- 소리: 효과음 → 브라우저 내장 음성으로 "닉네임님 금액 원 후원". 시청자가 끌 수 있는 "후원 음성" 버튼
- 제약: 사용자가 화면을 한 번 누르기 전에는 브라우저가 소리를 막음. 한국어 음성은 기기마다 다름(없으면 효과음·배너만)

## 반응형
- 데스크톱 1440 / 태블릿 768 / 모바일 390에서 모두 동작
- 좁으면 2단 → 1단으로 쌓임, 카드는 한 줄에 하나, 좌우 여백 40px → 16px
